# SYM-2P model eval pilot, 2026-11-12

First API-driven run of the `bench/` protocol in `EVAL.md`. Automation added in `bench/run-api.py`. Corpus unchanged: 10 hand-written paired tasks. This is a smoke run, not a benchmark.

## Configuration

- Models: `gpt-6-astra`, `gpt-6.1-sol`, efforts `low`, `medium`, `high`, six configurations in total.
- All 96 calls went out at `service_tier="flex"`. Zero 4xx, zero fallbacks, zero failures.
- Date 2026-11-12. Harness commit at run time: `9c3831c`.
- Prompts verbatim from the EVAL.md protocol: fresh call per form, verbatim answers, compile prompts carry sections 3 and 4 of `SPEC-V2-DRAFT.md`.

## What the raw outputs show

Cold read of v2 without the spec in context fails. Verbatim examples from `raw-responses.jsonl`:

- gpt-6-astra-medium, t01 v2: answers `1`, `2`, `1`, `Sections 3 and 5`, `*`. It echoed enum codes instead of decoding them.
- gpt-6-astra-medium, t08 (render): "Please provide the packet's opcode definitions, particularly `6`, `20`, `30`, `31`, and `34`, so I can translate each body expression into one plain-English sentence without guessing." It asked for the spec instead of rendering.
- gpt-6-astra-high, t09 (compile): `2|c901|mr1|1|2|1|1|80|60|(10 sym2p/1.0 (20 sec (1 2)))(11 (21 *))(12 (22 tester 0 1))|1|0|0` vs the reference `...|1||0`. The base field is wrong. Validator rejects it. Close, but not valid.
- Render t07 produced a faithful expression-by-expression gloss that contains none of the three key phrases. The scorer counts 0/3. The behavior is honest misreading, not format violation.

English forms also score under 70%, partly for strict-match reasons. gpt-6-astra, t01 v1: "SYM-2P/1.0 sections 3-5" misses the key `3-5`. "cos" misses `coordinator`.

Reviewers should read `raw-responses.jsonl` before quoting numbers.

Effort does not move cold-read performance in either model at this corpus size. v1 totals are 16-17/25 everywhere. v2 totals are 4-6/31 everywhere.

## What this does not claim

- This is not a benchmark. Ten hand-written tasks cannot support a capability claim.
- No model is being ranked. The two models differ by roughly one task.
- The v2 compression win (3.1x bytes on paired tasks, measured by `sym2-bench.py`) is unaffected by this result.
- The scorer is strict. Near misses are visible in the raw logs, not counted.

## Readings

1. Cold-read negative result, consistent with the paired negative results in the paper draft this repo supports. Frontier models without the grammar in context cannot reliably read or write SYM-2P.
2. The open question is the deployment shape: a receiver that holds the spec (like a parser holds a grammar). A spec-in-context arm would tell whether the gap is knowledge (fixable, by shipping the receiver spec) or capacity. That arm needs its own preregistration before any run. Estimated cost is under $1.
