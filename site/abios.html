POST handshake

Every PC runs POST at boot before loading an OS. In ABIOS, POST is the one-time session handshake: before references or deltas, peers exchange decode-sufficient minimal lexicon and schema (ack line plus context body). Mismatch → fall back to plain JSON or abort; never decode with a guessed lexicon. Normative detail in SPEC-ABIOS-3 §8.1. POST tokens are included in benchmark totals.

Why ABIOS?

ABIOS stands for Agent BIOS—the layer that lets agents talk without restating everything they already share. The name nods to IBM's Advanced BIOS (April 1987, PS/2: CBIOS for real-mode DOS, ABIOS for protected-mode OS/2). That ABIOS saw little use; the PS/2 line left VGA, PS/2 ports, and the 1.44 MB floppy (still the save icon). It does not claim ABIOS succeeded. Pairs with Synbios. ABIOS/3 was previously SYM-2P; v2 dense wire tokenized worse than JSON and was dropped.
