# ABIOS sealed-session benchmark

Token cost of sender authentication (SPEC-ABIOS-3.md section 8.2) on the bench lifecycles, encoder `refs`, tokenizer `o200k_base`. Generated by `scripts/protean-abios/auth_bench.py`; `make bench` verifies it.

Accounting: plain = POST (ack line plus minimal decoder context) + message lines. Sealed = sealed POST + message lines with seal lines interleaved and a close seal at the end. Overhead is sealed minus plain. The authenticated JSON column seals compact JSON lines with the same scheme and counts messages only (no POST), which favors JSON.

Bench key, kid, and sid are fixed public values, so tags (and their token counts) are reproducible.
